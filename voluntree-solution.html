Step 1–2 · Idea Convergence + Core Definition

The Final Solution

🧩

Problem

NGOs in rural India drown in paper surveys, WhatsApp voice notes, and disconnected spreadsheets — leaving critical needs unactioned and volunteers misallocated.

✅

Value Proposition

VolunTree converts chaotic field data into a live, AI-structured need map and surfaces the best volunteer match — in seconds, in any Indian language, with or without internet.

🎯

Differentiator

Not a dashboard. A decision engine. The data capture mechanism is the product — field workers change nothing about how they work; AI handles the rest.

01

Who are the users?

Field Workers — ASHA workers, ground volunteers; submit reports via WhatsApp voice/photo, zero app install needed.
NGO Coordinators — review AI-structured queue, approve assignments, monitor hotspots.
Volunteers — receive localized task briefs via FCM push; accept/decline on Flutter app.
NGO Leadership — view district heatmaps, urgency trends, outcome analytics.

02

The ONE core action

A field worker submits any messy input (photo of handwritten form, Hindi voice note, typed text) → VolunTree structures it, scores urgency, and surfaces the top-3 matched volunteers with explanations — all within 5 seconds.

03

What makes this different?

Most hackathon teams build volunteer portals. VolunTree builds a multimodal intelligence layer. Input is WhatsApp (500M Indians already use it). AI is Gemini (not keyword parsing). Matching is semantic + spatial (not nearest-neighbor). Offline works on ₹6,000 phones. Human is always in the loop.

Step 5 · AI Implementation

Where Gemini Works

A

Multimodal Extraction (Gemini Flash)

Input: Image of handwritten survey OR base64 audio clip OR raw text in Hindi/English/Hinglish.

Prompt pattern: Schema-constrained JSON extraction with few-shot examples. Model instructed to output ONLY valid JSON matching a fixed schema; low-confidence fields flagged with "confidence": 0.4 for human review.

# Example Gemini extraction prompt system: "You extract community needs from field reports. Always output valid JSON matching this schema exactly. Set confidence 0-1 per field. If unclear, flag for review." user: [IMAGE: crumpled survey in Hindi] output: { "location": "Village Dhangaon, Ward 4", "need_type": "water_access", "severity": "high", "beneficiary_count": 45, "deadline_hours": 48, "confidence": 0.88, "review_needed": false }

Runs: Cloud-side (Cloud Run). Fallback: cached responses for common need types when API unreachable.

B

Urgency Scoring (Rules + Gemini)

Stage 1 — Hard Rules: If child at risk, medicine deadline < 24h, or water for 50+ people → score ≥ 85 automatically.

Stage 2 — Gemini Features: Extract emotional distress signals, escalation language, repeat complaint flags from free-text description.

Final score: Weighted blend → 0–100 urgency index displayed on coordinator dashboard.

C

Volunteer Matching + Explanation (Gemini + Vertex)

Step 1: Vertex AI text embeddings for volunteer skill profiles + task descriptions → cosine similarity top-10 candidates.

Step 2: Filter by: language match, distance ≤ 15km, availability, gender constraint (if applicable).

Step 3: Gemini generates 1-sentence explanation per top-3: "Assigned to Priya because she speaks Marathi, completed 7 health visits in this block, and is 3.1 km away."

No auto-dispatch. Coordinator always approves. Builds trust, enables override.

Step 8 · Offline + Rural Strategy

Works Without Internet

💾

What Works Offline

Capturing new field reports (photo, voice, text). Viewing previously synced task list and volunteer profiles. Marking task completion with notes. Viewing cached need map.

🔄

Syncs When Online

All queued reports upload to Cloud Storage. Gemini extraction triggers automatically. Firestore offline cache reconciles with server state. FCM push delivers pending notifications.

📦

Local Storage

Flutter Hive store for form drafts and offline captures. Firestore SDK offline persistence for real-time documents. Audio files cached locally until sync. No CRDT complexity — last-write wins for non-critical fields; admin flags conflicts for critical records.

📶

Poor Connectivity Behavior

App detects connectivity state via Flutter's connectivity_plus package. Low-bandwidth mode: text-only sync, deferred image upload. SMS fallback for critical volunteer alerts (Exotel integration, Phase 2).

Step 11 · Risks + Backup Plans

What Can Go Wrong

Risk

Gemini API Fails / Rate Limited

During live demo, API quota exhausted or connectivity issues cause extraction to fail.

Mitigation

Pre-cached Demo Responses

Pre-process 5 demo inputs; store outputs in Firestore. Toggle a "demo mode" flag that serves cached data. Judges see identical experience.

Risk

WhatsApp Sandbox Instability

Twilio sandbox connection drops mid-demo or message delivery is delayed.

Mitigation

Direct App Upload Fallback

The Flutter app has its own upload screen (camera + audio). If WhatsApp fails, demonstrate via in-app capture. Identical AI pipeline, different input channel.

Risk

Gemini Misreads Handwriting

OCR/extraction produces wrong fields from badly lit, crumpled paper in demo.

Mitigation

Human Review Queue

Low-confidence fields are always flagged and shown in the review queue. This is a feature, not a bug — it demonstrates the human-in-the-loop design philosophy live.

Risk

No Historical Volunteer Data

Matching engine has no completion history to rank volunteers meaningfully.

Mitigation

Seeded Demo Data

Pre-load 20 realistic volunteer profiles with seeded history. Matching works immediately. Real data populates over time in production.

Step 14 · Why This Will Win

The Winning Edge

01

Technical Strength That Judges Can See

Multimodal Gemini (image + audio + text in one call), semantic embeddings for matching, schema-constrained JSON extraction, offline Firestore sync, FCM dispatch, Google Maps geo-clustering. Every component is visible in the 3-minute demo. No hand-waving about "our AI backend."

02

Real-World Empathy Over Engineering Theater

Most teams build for the demo, not for deployment. VolunTree meets users where they are: WhatsApp, voice notes, handwritten forms. Human-in-the-loop approval prevents AI from making dangerous autonomous decisions. Trust is designed in, not bolted on.

03

Ruthless Scope Discipline

No GNNs. No reinforcement learning. No satellite fusion. No P2P mesh networks. Every feature cut was a deliberate decision to make the remaining features excellent. What's left is buildable in 4 days and demoable in 3 minutes. Judges see a complete product, not a 30-slide vision deck with a broken prototype.

04

India-First = Globally Defensible

Designing for the hardest constraints (2G connectivity, ₹6,000 phones, multilingual dialects, low literacy, no app installs) produces a system that works everywhere. Urban NGOs in São Paulo or Nairobi are easier to serve than a field worker in Bhor Block with intermittent BSNL coverage.

05

Clear UN SDG Story

SDG 1 (No Poverty): faster resource routing to the most vulnerable. SDG 3 (Good Health): medical volunteers matched to health needs before escalation. SDG 10 (Reduced Inequalities): silent rural zones surfaced, not just loud connected ones. SDG 11 (Sustainable Communities): coordinated local response infrastructure. SDG 17 (Partnerships): NGO network effect grows the shared intelligence layer.
